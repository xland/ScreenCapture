1. Open the folder window and navigate to the following path: `%appdata%\ScreenCapture\Lang`.
2. Download the language file and copy it to the aforementioned path.
3. Restart the application.

> Create a Lang subdirectory in the same folder as ScreenCapture.exe and put the language files there. The application will read the language files from this directory.
